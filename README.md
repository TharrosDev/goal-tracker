# Goals

A single-page tracker for money goals (save $2,400 for a road bike) and milestone goals (get the job).
Add a target, an optional deadline, and log progress as you go. Money goals show a progress bar, what's
left, and the weekly rate needed to hit the deadline.

Everything is stored in your browser's `localStorage` — no account, no server, no data leaves the device.
That also means each browser has its own list, and clearing site data wipes it, so use **Export backup**
now and then.

## Running it

Open `index.html` in a browser. That's the whole build step.
